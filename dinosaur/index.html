    Install on iPhone

    1. Open the published game link in Safari.
    2. Tap Share (the square with an arrow).
    3. Tap Add to Home Screen.
    4. Leave Open as Web App turned on if you see it.
    5. Tap Add.

    iPhone doesn’t show an automatic install pop-up, so these steps are the way to add it. After the first visit, the game can be played offline. Offline play needs the game to be hosted over HTTPS (local testing on localhost also works).

    Reset progress?

    This clears the personal best, fossils, discoveries and unlocked levels on this device.
