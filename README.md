# Walker & Birkley's Games

Play: https://chase-allen-max.github.io/walkergame/

| Game | Folder |
|---|---|
| Seahawks Gridiron | `seahawks/` |
| Walker's Dinosaur Adventure | `dinosaur/` |
| Walker's Rink | `hockey/` |
| Birkley's Doll Workshop | `dolls/` |

Each game is a standalone web app that installs to a phone's home screen and works offline.

`tools/seahawks-sim.js` plays thousands of Seahawks Gridiron games headlessly to check balance: `node tools/seahawks-sim.js 2000 300`.
